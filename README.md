# GitHub Treasure Hunter

A modern dark-mode Streamlit dashboard for discovering GitHub repositories by keyword, language, stars, forks, and a calculated treasure score.

## Features

- Search repositories by keyword using the GitHub Search API
- Filter by programming language and minimum stars
- Sort results by stars, forks, or treasure score
- Beautiful repository cards with key metrics
- Progress bar and loading spinner during searches
- Sidebar controls
- Charts powered by Streamlit and pandas
- Local SQLite search history

## Run

```bash
pip install -r requirements.txt
streamlit run app.py
```
